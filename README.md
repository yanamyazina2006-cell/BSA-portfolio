# REU-Map
# Интерактивная карта РЭУ им. Г.В. Плеханова

**Роль:** Системный аналитик

## О проекте
Разработка концепции мобильного приложения для навигации по кампусу РЭУ.

- Проведён анализ 79 пользователей: выявлены ключевые боли — поиск аудиторий (58%), переходы между корпусами (49%), отсутствие оффлайн-режима.
- Выполнен конкурентный анализ вузовских приложений (Камтус, ЛКС, Универ.Онлайн и др.).
- На основе данных сформулированы функциональные требования и приоритеты MVP.
